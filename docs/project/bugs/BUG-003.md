# BUG-003: moveGroup with an undefined or null source id retags every ungrouped task

- Severity: Low
- Priority: P3
- Status: Closed (Verified 2026-11-09, fix commit 3d9e499; retest evidence qa/evidence/T2-unit/probe-undefined-from-retest.txt)
- Found in: T2 (src/store.js, uncommitted)
- Related TC: T2-movegroup-undefined-from-probe; requirements R69, R70

## Environment
Node unit level, branch task-groups, uncommitted store.js.

## Steps to reproduce
1. Create a store with one ungrouped task.
2. Call `store.moveGroup(undefined, "h")`.

## Expected
Nothing moves, `{ moved: 0 }`, because there is no source group.

## Actual
`{ moved: 1 }` and the ungrouped task now has `groupId: "h"`. The filter `t.groupId !== fromId` treats a missing groupId as equal to an undefined fromId. A caller bug (for example a deleted or unset group id) would silently assign every ungrouped task to a group, or with null as target ungroup nothing visible.

## Evidence
docs/project/specs/task-groups/qa/evidence/T2-unit/probe-undefined-from.txt

## Suggested fix
Return `{ moved: 0 }` unless `typeof fromId === "string" && fromId`.
