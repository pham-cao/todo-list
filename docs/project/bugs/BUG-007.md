# BUG-007: The "added to a hidden group" notice stays after the filter is changed to show that group

- Severity: Low
- Priority: P3
- Status: Closed (Verified 2026-11-10)
- Found in: T7 (src/app.js, `notify` and the filter `change` handler, uncommitted)
- Related TC: TC-task-groups-T7-27 (failed); requirements R47, R43

## Environment
Branch task-groups, uncommitted T7 build, http://localhost:4173, Chromium 1440 and Pixel 7, locale vi-VN.

## Steps to reproduce
1. Seed groups Công ty and Nhà with tasks on today. Choose "Công ty" in "Lọc theo nhóm".
2. Set the add choice to "Nhà" and add the task "Mua rau". The notice appears: Đã thêm việc vào nhóm "Nhà". Nhóm này đang được ẩn bởi bộ lọc.
3. Change the filter to "Nhà" (or "Tất cả nhóm").

## Expected
The notice is gone, or no longer says the group is hidden, because the group is now on screen.

## Actual
The notice stays visible with the same text, so it claims that Nhà is hidden while its section is shown. It clears only on the next add, a day move or midnight.

## Evidence
- docs/project/specs/task-groups/qa/evidence/TC-task-groups-T7-27/runner-output.txt
- Automated: tests/e2e/groups.spec.js, `test.fail` "the hidden group notice goes away when the filter changes"

## Impact
Cosmetic and mildly confusing for the owner and a screen reader user, no data is wrong.

## Suggested fix
Call `notify(null)` at the start of the filter `change` handler. Then remove `test.fail` from the test.
