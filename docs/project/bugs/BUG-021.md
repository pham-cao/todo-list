# BUG-021: Adding a task by keyboard into a group that already has a section does not end a running mouse drag (into a group without a section it does)

- Severity: Low
- Priority: P3
- Status: Closed (Verified 2026-11-11)
- Found in: drag-drop T7 (uncommitted src/drag.js and src/app.js), QA probe 2026-11-11
- Related TC: TC-drag-drop-EXP-T7-keyboard-add; requirement R20, NFR4 (decision "renderList cancels first": adding a task by keyboard during a drag cancels)
- Owner: fe

## Environment
Chromium desktop, 1280x720, 4 groups, a task list with a Sức khỏe section of 20 rows. The mouse button held down on "Trả lời email" (group Công ty).

## Steps to reproduce
1. Seed the groups and tasks, choose the group Công ty (it has a section) in the add form.
2. Press on the row "Trả lời email" and move 60 px so the drag starts; keep the button down.
3. Focus the add field, type "Đi bộ", press Enter.
4. Look at the page. Repeat with the group Học (no section).

## Expected
Both cases end the drag as a cancel, as decisions.md for T7 says (every re-render path cancels first): no slip, strip, placeholder or is-dragging, one announcement "Đã hủy. Việc vẫn ở nhóm "Công ty".".

## Actual
Into Học (no section yet) the list is rebuilt and the drag is cancelled as expected. Into Công ty the row is added in place, renderList does not run, and the drag goes on: slip, strip, placeholder, cue and is-dragging stay, no announcement, until the button is released. The release then cancels or drops normally, the added task is the only change, and the next drag works, so nothing is stuck for good. The behaviour differs by whether the group has a section.

## Impact
Low: a mouse button is held while typing, a rare mix. No data change.

## Evidence
- docs/project/specs/drag-drop/qa/evidence/TC-drag-drop-EXP-T7-keyboard-add/
- docs/project/specs/drag-drop/qa/evidence/T7-regression/qa-probe.spec.js (the probe source)

## Suggested fix
Make the in-place add path call drag.cancel() as well (for example at the top of the add handler), or amend the decision to say the drag continues.
