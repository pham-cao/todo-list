# BUG-022: A cancel caused by a rename or deletion of the group in another tab names the new name, or Chưa phân nhóm, not the group read at pick up

- Severity: Low
- Priority: P3
- Status: Closed (Won't fix, as designed 2026-11-11)
- Found in: drag-drop T7 (uncommitted src/drag.js and src/app.js), QA probe 2026-11-11
- Related TC: TC-drag-drop-EXP-T7-group-renamed-deleted, TC-drag-drop-T7-07; requirement R21, R22 (the cancel announcement names the task's group; the T7 brief says the group read at pick up)
- Owner: fe

## Environment
Chromium desktop and Pixel 7, 4 groups. Storage event dispatched with the groups key changed during a drag of "Trả lời email" (group Công ty).

## Steps to reproduce
1. Start a drag of "Trả lời email" (group Công ty).
2. Write the groups key with Công ty renamed to "Công ty mới" and dispatch the storage event (second run: Công ty removed).
3. Read #sr-status.

## Expected
Đã hủy. Việc vẫn ở nhóm "Công ty". (the group read at pick up, as every other interruption announces).

## Actual
Renamed: Đã hủy. Việc vẫn ở nhóm "Công ty mới". Deleted: Đã hủy. Việc vẫn ở nhóm "Chưa phân nhóm". The drag itself ends cleanly before the groups are replaced, but dropOrCancel builds the text inside requestAnimationFrame, after the storage handler has replaced `groups`, so the name is looked up late.

## Impact
Low: a screen reader user hears a name that was not read at pick up; R22 says "current group", so the new name can be argued as correct. Needs a PM decision; the brief asks for the pick up name.

## Evidence
- docs/project/specs/drag-drop/qa/evidence/TC-drag-drop-EXP-T7-group-renamed-deleted/
- docs/project/specs/drag-drop/qa/evidence/TC-drag-drop-T7-07/
- docs/project/specs/drag-drop/qa/evidence/T7-regression/qa-probe.spec.js (the probe source)

## Suggested fix
Read the name before the rAF (const name = groups.get(own)?.name at the top of dropOrCancel), or decide that the current name is intended and update the TC.

## Retest
Decision 2026-11-11 (PM, decisions.md T7): works as intended. R22 announces the group the task is in now, so "Công ty mới" or "Chưa phân nhóm" after another tab renames or deletes the group is the true current group. The oracle of TC-drag-drop-T7-07 and the EXP group-renamed-deleted case is changed to match, and the probe now expects the current name. Retest: renamed announces "Công ty mới", deleted announces "Chưa phân nhóm", one announcement, no leftovers, mouse and Pixel 7.
