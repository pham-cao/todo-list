# BUG-015: The info slip for a move into a hidden group runs off a 360 px screen when the task text is 200 characters with no space

- Severity: Medium
- Priority: P3
- Status: Closed (Verified 2026-11-10, T2 attempt 2)
- Found in: drag-drop T2 (uncommitted changes in src/app.js), TC-drag-drop-T2-11
- Related TC: TC-drag-drop-T2-11; requirement R15 (decisions.md: slip text with the task text)

## Environment
Chromium (Playwright desktop project, viewport set to 360 x 740), clock fixed 2026-11-09 09:00 +07, locale vi-VN, npm start on port 4173.

## Steps to reproduce
1. Seed a task in group Công ty whose text is 200 times the letter A, plus a second Công ty task, and a group Nhà.
2. Set the filter to Công ty.
3. Press Sửa on the long task, choose Nhà, press Lưu.

## Expected
The info slip shows Đã chuyển việc "AAAA..." sang nhóm "Nhà". wrapped inside the slip, with no sideways scroll (the task rows and dialog texts already use overflow-wrap: anywhere).

## Actual
The text does not break, it runs past the right edge of the slip and the screen. documentElement.scrollWidth minus clientWidth is 1707 px, so the whole page scrolls sideways. A 200 character text that has spaces wraps correctly (overflow 0).

## Impact
Only text with a very long unbroken word, for example a pasted link. The move itself and the data are fine, but the slip is the only message the owner gets, and the page layout breaks on a phone. The same rule affects the older "Đã thêm việc vào nhóm" slip when a group name is a long unbroken word.

## Suggested fix
Add overflow-wrap: anywhere to the text of .alert (for example `.alert p { min-width: 0; overflow-wrap: anywhere; }`) in docs/project/design-system.css and its copy used by the app. Then remove test.fail in tests/e2e/groups.spec.js (test "a 200 character task text without spaces wraps ...").
