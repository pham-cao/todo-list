# BUG-019: The T4 test "a header, a row and the space inside a section are targets" fails intermittently since auto scroll (T6)

- Severity: Medium
- Priority: P2
- Status: Closed (Verified 2026-11-11)
- Found in: drag-drop T6 (uncommitted src/drag.js), regression run of the T3 to T5 drag tests
- Related TC: TC-drag-drop-T4 drop target case (tests/e2e/drag.spec.js line 453); TC-drag-drop-T6-11; requirement R31
- Owner: fe

## Environment
Chromium desktop project, 1440 x 900 (the drop describe), clock fixed 2026-11-09 09:00 +07, vi-VN, 3 groups and 4 tasks (the T3 seed), npm start.

## Steps to reproduce
1. Run `npx playwright test tests/e2e/drag.spec.js -g "a header, a row and the space" --workers=2 --repeat-each=6`.
2. Full suite run `npx playwright test --workers=2` also failed once in the same test (668 passed, 1 failed, 69 skipped).

## Expected
The test passes every time, as it does on the T5 version of src/drag.js.

## Actual
2 of 6 runs fail at line 471 (`.drag-slip__to` missing); the run before it (line 469) saw the target. With the T5 `src/drag.js` (git stash of that file only) 6 of 6 pass. A later run of the whole file with --repeat-each=3 (desktop) passed 105 of 105, so it is timing dependent.
Cause found by tracing: the row "Cắt tóc" is the last row and sits at y 773 to 796, inside the 64 px zone above the strip (754 to 818). The test moves the pointer onto it, the page auto scrolls 76 px to its end, and the row moves up to y 697, so the pointer ends over the sheet's bottom margin and the target is cleared. The mutation log shows the mark on "none" set and removed within about 65 ms while scrollY goes 0 to 28.

## Impact
The product behaves as R31 describes (the row is in the zone, so the page scrolls). The defect is the test: it is now timing dependent, so the exit criterion "all tests pass" is not reliable and CI can go red without a code change. No data impact.

## Suggested fix
In the test, scroll the page first so "Cắt tóc" is clear of the zone (or add rows above it / use a taller viewport such as 1440 x 1100), then hover it. Check the other T4 tests that hover rows near the strip with --repeat-each.
