# BUG-008: Sửa on a lower row of the scrolling group list leaves Lưu and Hủy below the visible part

- Severity: Low
- Priority: P3
- Status: Closed (Verified 2026-11-10)
- Found in: T8 (docs/project/design-system.css, scrolling `.group-rows`, and src/manage.js `startEdit`, uncommitted)
- Related TC: TC-task-groups-T8-24 (failed); requirements R35, R36, R64

## Environment
Branch task-groups, uncommitted T8 build, http://localhost:4173, Chromium Pixel 7 style viewport 390x700 (also 360x640 and 640x360), 20 groups, locale vi-VN.

## Steps to reproduce
1. Seed 20 groups. Open "Quản lý nhóm" on a phone sized screen.
2. Scroll the rows to the end and press Sửa on the last group.

## Expected
The edit block (name, colours, Hủy and Lưu) is brought fully into view, as the rest of the app does for an edit in place.

## Actual
The input gets focus, but the list keeps its scroll position (855 of 984). The row grows by about 120 px and Lưu sits 79 px below the visible bottom of the list (and below the screen at 700 px height). A touch user has to scroll to find Lưu or Hủy. Enter in the input still saves, and Tab scrolls the focused button into view, so nothing is blocked.

## Evidence
- docs/project/specs/task-groups/qa/evidence/TC-task-groups-T8-24/probe3.png and probe-360x640-edit.png
- Automated: tests/e2e/groups.spec.js, `test.fail` "Sửa on the last of 20 groups brings the whole edit block, with Lưu, into view" (mobile project)

## Impact
Usability only, for owners with many groups on a phone. No data is wrong.

## Suggested fix
After `startEdit`, call `scrollIntoView({ block: "nearest" })` on the editing row's `.group-row__edit-actions` (or the row), then remove `test.fail` from the test.

## Retest (2026-11-10)
FE added scrollIntoView({block:"nearest"}) in startEdit and removed test.fail. The test passes on mobile. Short screen edge: 640x360, 360x640, 390x700 and 360x500, first, middle and last row, all show both the name input and Lưu inside the visible list. Verified, then Closed. Evidence: qa/evidence/TC-task-groups-T8-24/retest-*.
