Group header

Prototype on the paper notebook design, for review

"Quản lý nhóm" moves into the page header, under "Về hôm nay", and creating a group moves out of the add form into the "Nhóm việc" card, where "Thêm nhóm" opens a small sticky note that asks only for the name. Every screen opens in a browser on its own; links and buttons walk you through the flow. Try each one at desktop width and on a phone (390 px), and switch your system to dark mode to see the night notebook.

Flow 1: reach the groups from the header

  • Day page with groupsHeader with Quản lý nhóm under Về hôm nay; the add choice without Nhóm mới...; the filter alone on its line
  • Day page with no groupsThe group bar is hidden, so no empty line is left
  • Nhóm việc cardThêm nhóm is the first line, above the rows
  • Nhóm việc card, no groupsThêm nhóm above "Bạn chưa có nhóm nào."

Flow 2: create a group

  • Tạo nhóm mớiCentred note on desktop, bottom sheet on phones; the swatch shows the colour it will get
  • Name typedEnter or Tạo nhóm creates it
  • Group createdNew last row with a short wash, focus back on Thêm nhóm
  • First groupWith no groups the next colour is Vàng
  • Phone keyboard openCheck at 360 by 640: the field and buttons stay above the keyboard

Validation and errors

  • Empty nameVui lòng nhập tên nhóm.
  • Name too longTên nhóm tối đa 30 ký tự.
  • Name already usedTên nhóm này đã có rồi.
  • 20 groupsThe limit message shows as soon as the box opens
  • Storage failedThe storage slip inside the card

Key design decisions

  • "Về hôm nay" and "Quản lý nhóm" share one right hand column at the end of the day navigation, so the two labels end on the same vertical line. Quản lý nhóm keeps its pen coloured tag button. Below 452 px it is the tag icon only, as before, now drawn with a thin pen outline so it reads as a button on its own.
  • "Thêm nhóm" is a blank line at the top of the card with a hand drawn plus, like starting a new line on an index card. It sits outside the scrolling rows, so it stays visible with 20 groups; the rows give back its height so the card still fits the screen.
  • The box reuses the delete group note: the same yellow paper, tape, corner label, title and button row. The corner label and the swatch beside the field are both in the colour the group will get, so the colour is previewed without a picker. On phones the note docks to the bottom as a sheet, so it rises with the keyboard and the buttons stay under the thumb.
  • Errors use the existing field error line under the input, in red with an icon, and the typed text is always kept. The 20 group message shows at once, as the owner chose.
  • After creating, the box closes and the new row gets the same short colour wash a moved task gets, so the result is visible without a toast; focus goes back to Thêm nhóm for the next group.
