Daily task log

Prototype, version 3: paper notebook

A clickable prototype of the one screen where the owner adds, views, completes, edits, and deletes today's tasks. This version turns the whole app into a sheet of ruled notebook paper, as the owner asked. Flows, states and requirement coverage (R1 to R30) are unchanged, and all interface text is Vietnamese, word for word from the requirements. Dark mode follows your system setting, so switch your OS to dark to see the notebook at night.

Start here

Open today with tasks, tick a box to see the pen tick and the strike line, hover a line or press Tab for Sửa and Xóa, and tick every box to see the star stamp. On a phone, swipe a line left. The flows and the screen inventory are in flows.md, the visual rules in design-system.md, and the review notes in critique.md.

Screens and states

  • Today, defaultSeven tasks on the ruled sheet, two done. Checkboxes really toggle.
  • Row actions revealedA line swiped left on a phone, or hovered and focused on desktop.
  • All doneThe progress circle closes and a red star stamp presses into the margin once.
  • Today, emptyFirst visit, or stored data missing or unreadable. A doodled cà phê phin.
  • Add errorEmpty text, with the too long variant below it.
  • Edit modeThe line is highlighted with Hủy and Lưu on the next line, and the edit error variant below.
  • Delete confirmationA sticky note taped over the page.
  • Storage unavailableA warning slip clipped into the header while the app keeps working in memory.
  • New day after midnightA fresh page dated Tuesday, empty list.

Key design decisions

  • The ruling is the system. The line pitch is 44 px, which is also the row height and the tap target, so task text, inputs, errors and buttons all sit exactly on the lines, and long tasks wrap onto the next line like real handwriting.
  • Marks live in the margin, words live on the lines. The checkbox, the pen that starts a new line, and the progress circle all sit left of the pink margin line.
  • Ink, not widgets: a blue-black pen tick that overshoots the box, a pen strike through done tasks, and a red star stamp when every task is done. The stamp is the only celebration, with no new text.
  • Small paper details carry the theme: punched holes, washi tape on the date, a sticky note for the delete question, a clipped slip for the storage warning, and a doodle for the empty page. Type stays Aptos with black ink so it reads calmly and renders Vietnamese well.
  • Sửa and Xóa appear on hover or keyboard focus on desktop, and by swiping the line left on phones. The swipe uses native scroll snap, so keyboard focus opens the row by itself and screen readers reach both buttons without a gesture.
  • Dark mode is a notebook at night: charcoal paper, warm white ink and a pale blue pen, following the system setting.
  • The top right of the header stays empty for the later day navigation, which will feel like turning pages.
